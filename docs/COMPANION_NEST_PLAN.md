## Verdict by area

### Works (keep)

- Single canonical state machine (`CompanionStore`) with persisted
  settings and a versioned state file; `Player` runs on one `Timer`
  and single-frame reels never tick.
- Manifest v2 vocabulary: 25 default animations (idle, blink, look,
  preen, stretch, hop, greet, walk, hover, takeoff, fly, land, perch,
  peek, drag, talk, think, listen, work, approve, celebrate, deny, worry,
  error, sleep) and the assistant-state map covering resting, listening,
  thinking, acting, speaking, success, warning, denied, error.
- Suppression: lock, fullscreen, game mode, area picker, Control Center.
  Disabling unloads the surface.
- Reduced motion replaces bob/bounce/fly by jump cuts.
- Asset pipeline with drift gates (`derive-companion-assets.py --check`,
  `preview-companion-assets --check`) and tests
  (`test_companion_assets.py`, `test_companion_runtime.py`).

### Partial

| Area | Gap |
| --- | --- |
| Hornero identity | Reads as a generic wren: cocked tail, short beak, crest-like tuft in `hop`, russet legs. A rufous hornero has a longer straight pointed bill, plain rufous upperparts, pale throat, upright stance, uncocked tail, pinkish legs. |
| Frame consistency | `peek` is a hard square crop (visible straight edges at the left and bottom); `fly` has a stray pixel; silhouette edges are jagged from chroma keying. Proportions drift between `idle`, `walk`, `think`. |
| Anchors | Only `feet` and `center`; no per-frame pivot, so takeoff to fly shifts the body. |
| Nest | Five flat stages (twigs, cup, dome, home); flat vector, travels with the sprite window (not a habitat), no electronics, no lighting, no states other than progress. |
| Control Center pane | One 1234-line `CompanionPane.qml` mixing General, Assistant, Hermes, Permissions, Personality, Character. No Habitat or Interaction pane; no live preview, no per-section reset. |
| Docs | `docs/COMPANION.md` still describes the v1 vocabulary (4 animations) and says "Overlay layer" in a code comment while the code uses `Bottom`. |

### Redesign

1. **Input region.** The layer surface is sized to the content column
   (`implicitWidth/Height: stack.*`) with no `mask`, so the transparent
   corners of the 128 px sprite square and nest image block clicks on
   whatever is below. Requirement: no invisible click blockers. Fix: an
   explicit `Region` covering only the visible bounding box of the sprite,
   the nest, and the open bubble or chat card.
2. **Nest as a habitat, not a sprite prop.** Separate surface or separate
   composited layer with its own position, anchor, monitor, scale and
   lifecycle (resting, working, building, sleeping, summoned, hidden);
   Javi returns to it; hidden state destroys the surface and every timer.
3. **Pane split** into modular components: Appearance, Habitat,
   Behaviour, Interaction (this workstream); Assistant is owned by the
   Workbench agent.

### Missing

- Habitat states and lighting; tiny electronics (CRT, antenna, radio,
  indicator lights) whose lights reflect real states only: assistant
  connected, running, awaiting approval, failed (from `AssistantBridge`),
  mode, quiet hours. No fake telemetry.
- Per-mode policy for the nest (Focus quiet or hidden, Everyday cozy,
  Signal rich, Gaming never interferes, Studio calm); overrides never
  silently reset (build on the policy in shell#606).
- Chromatic integration: recolour electronics, lights and accents, never
  Javi's anatomy.
- Multi-monitor/scaling checks for the habitat; fullscreen suppression
  already exists.
- Measured CPU for hidden, idle and active (H4).
- PluginKit extension points for skins, accessories, nest appearances
  and animation packs (proposed to the PluginKit agent via the RFC; no
  fork of the framework; shell#611 is the first hook).

## Art needs from the maintainer

New bird poses are AI-generated keyframes in this repository. This
workstream can ship original procedural art (nest, electronics, lights,
matting fixes, anchors) but cannot honestly replace the bird's hand-drawn
anatomy. For an unmistakable rufous hornero the maintainer should supply
or approve: (a) a corrected master idle (longer straight bill, plain
rufous back, pale throat, upright posture, uncocked tail, pinkish legs),
(b) a 3/4 listening and a thinking pose at a tiny CRT, (c) a
sleeping-in-nest pose. The pipeline then regenerates everything else.
