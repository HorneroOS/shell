## Reproduction

From a running Hornero Shell session, run:

```sh
./scripts/perf-baseline.sh --samples 5 --interval 1 --format json
```

The raw JSON report is intentionally not committed because it includes
machine and session details. The run did not use `--restart`.

## Limits of this capture

- This is not a clean-session or cold-start measurement. Cold-start
  (greeter→shell-ready→first frame) and per-surface frame cost remain
  unmeasured; they are tracked in the baseline issue and need the
  disposable QA harness, not a daily-driver session.
- RSS includes shared file-backed mappings; PSS is the proportional
  figure. Anon PSS grew relative to the 2026-10-14 capture while total
  PSS stayed similar; the captures differ in source revision, session
  age, and loaded surfaces, so this does not establish a regression or
  an improvement — it is a prompt for a controlled A/B run.
- The measurements do not establish a memory leak. They show readings
  across this short sampling window only.
- IPC is one `lock isLocked` round trip, not general shell
  responsiveness, and no frame-time data is implied.
