# Spectrum meter: Repeater vs SpectrumMeter (2026-11-18)

Caelestia-recovery item 7. One `SpectrumMeter` scene-graph item now draws a
whole spectrum (Media tab well, desktop visualiser), with VU ballistics, and
sleeps once every band settles. The cava sampler also skips its FFT on
silence that has already drained to zero.

## Method

`tests/perf/spectrum/run-spectrum-cpu.py` runs
`tests/perf/spectrum/harness.qml` with the Qt 6 `qml` runtime on the
offscreen platform and reads the process CPU time (utime + stime) over
20 s after a 4 s warm-up, 3 trials per case, median reported. The harness
draws the two users at once (45-band segmented well + the two desktop
columns, 1280x720):

- `old`: the previous structure (a Repeater of segment meters, each a
  Repeater of Rectangles; one Rectangle per band per side with a 160 ms
  Behavior), loaded against a plugin build of `origin/main`.
- `new`: three `SpectrumMeter` items, loaded against this branch's build.
- `idle`: a real `CavaProvider` on the default sink monitor with nothing
  playing.
- `play`: synthetic values at 86 Hz (the cava frame rate), no sampler.

Two renderers: `gpu` (Qt RHI on OpenGL through an offscreen pbuffer, the
real GPU, no window shown) and `software` (Qt Quick software raster).

Development host, run inside the host's resource-capped scope. This is a
harness, not the full shell; the full-shell idle budget is tracked in #651.

## Results (CPU %, median of 3)

| Renderer | Case | old | new |
| --- | --- | ---: | ---: |
| gpu | idle, both users | 0.75 | 0.25 |
| gpu | play, both users | 3.65 | 1.60 |
| gpu | play, well only | 1.90 | 1.40 |
| gpu | play, desktop only | 3.45 | 1.20 |
| software | idle, both users | 0.65 | 0.25 |
| software | play, both users | 24.60 | 27.70 |
| software | play, well only | 5.05 | 3.30 |
| software | play, desktop only | 19.75 | 23.95 |

## Reading

- Idle drops by about two thirds on both renderers: the meters stop their
  frame clock once settled, and the sampler no longer runs the FFT on
  drained silence.
- With the GPU (how the shell renders on real hardware) playing costs less
  than half of the Repeater version.
- On the software rasteriser the desktop columns cost more: the faster VU
  attack changes more pixels per frame than the old 160 ms smoothing, and
  the software renderer pays per pixel. The segmented well is still
  cheaper there. Software rendering is only a fallback for the shell.
